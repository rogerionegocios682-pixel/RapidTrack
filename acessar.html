Delivery_OS

Abra o terminal na pasta do projeto e rode o comando abaixo. Depois clique em Abrir o sistema.

1. Subir o servidor

npm run dev

Se o npm falhar, use: 

& 'C:\Program Files\nodejs\node.exe' node_modules\next\dist\bin\next dev
Aguardando verificação…

2. Abrir

http://localhost:3000/login
