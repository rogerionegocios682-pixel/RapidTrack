Acesso ao sistema

Painel de entrada do sistema de gestão de entregas e motoboys. Escolha uma das telas abaixo para começar.

verificando servidor… Verificando http://localhost:3000

Entrar

→

Acesse com seu e-mail e senha. É por aqui que você entra no painel.

/login

Criar conta

→

Auto-cadastro. O primeiro usuário do sistema vira Administrador.

/cadastro

Esqueci a senha

→

Solicita um link de recuperação para redefinir a senha.

/esqueci-senha

Redefinir senha

→

Troca a senha usando o token recebido por e-mail.

/redefinir-senha

Painel

→

Dashboard com corridas, motoboys, empresas e taxas. Exige login.

/dashboard
Servidor desligado? Se os links não abrirem, inicie o sistema no terminal, dentro da pasta do projeto, com npm run dev (ou node node_modules/next/dist/bin/next dev) e recarregue esta página.
Usuário administrador já cadastrado: admin@deliveryos.com
A senha está guardada apenas como hash (scrypt) e não pode ser recuperada. Se você não lembra, use Esqueci a senha — o link aparece no terminal onde o servidor está rodando.
